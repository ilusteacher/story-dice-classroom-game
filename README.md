# Story Dice – Interactive Classroom Game

A playful classroom storytelling game where students roll different dice to create fun and imaginative story prompts.

## Features
- 6 story dice: character, setting, object, problem, action, twist
- Random team/class naming
- Story starter sentence generator
- Student writing panel for collaborative storytelling
- Round and score tracking

## Run locally
Open `index.html` directly in a browser, or serve the folder with a small local server:

```bash
cd story-dice-classroom-game
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project structure
- `index.html` – page structure
- `styles.css` – styling and layout
- `script.js` – dice logic and game behavior
